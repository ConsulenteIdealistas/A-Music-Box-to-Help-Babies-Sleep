# 土台ノイズの目標: ブラウンかピンクか — 抽出は何を決めたか (2026-11-16)

## 結論を先に

- **抽出はブラウン (-6 dB/oct) かピンク (-3 dB/oct) かを決められない。** 傾きの
  直接の証拠である Attenuation_dB_oct は A層×Include で **5値しかない**
  (6, 6, 12, 12, 96)。design_stats_summary.md 自身が「n is far too small
  to fix a design value」と明記している。96 はハイパス・マスキングノイズの
  傾き (PMID 1880297) で、残りは刺激・フィルタの傾き 6–12 dB/oct。
  どれも「子宮内の伝達の傾き」ではない。
- だから傾きの選択は**文献の帰結ではなく、試聴による設計判断**になる。
  「完全に合ってるところのみで進める」原則に照らすと、ここを抽出の数字で
  正当化してはいけない。
- 抽出が決めたのは別にある: 周波数 中央値 **1500 Hz** (Q1 500)、音圧
  中央値 **60 dB**。これらは土台設計の目標として採用済み。

## 現行ベッドの実測 (2026-11-16, `~/workspace/your_files/lullaby-mix/bed_only.wav` を再測定)

方法: 8192点 Hann 窓・50% オーバーラップでパワースペクトルを平均し、
各帯域で log2(周波数) に対する回帰傾きを取った。

| 帯域 | 傾き |
|---|---|
| 200–400 Hz | -6.5 dB/oct |
| 400–800 Hz | -12.2 dB/oct |
| 800–1600 Hz | -15.9 dB/oct |
| 1600–3200 Hz | -16.2 dB/oct |
| 200–800 Hz (合算) | -9.7 dB/oct |
| 800–3200 Hz (合算) | -16.3 dB/oct |

50–100 Hz は心音の基音 55 Hz で突出 (以前の測定と一致)。要するに現行ベッドは
400 Hz ローパス×3段のせいで **400 Hz より上で -12〜-16 dB/oct と急落**しており、
ブラウン (-6) とピンク (-3) の**どちらから見ても切りすぎ**である。
この過剰な切り落としは、ブラウン/ピンクの選択とは無関係に直す対象。

## 用意した聴き比べ (ベッドのみ・音楽なし・心音は同一)

`audio/render_bed_variants.py` で生成。心音層は現行と同一 (70 BPM・55 Hz)、
フロー層は同じ種のホワイトノイズに同じ心拍同期のうねりを掛け、
整形だけを変えた。2案ともフロー層の RMS を現行フローに合わせてあるので、
音量の違いではなく**スペクトル形だけ**の聴き比べになる。

| ファイル | 作り方 | 実測の傾き |
|---|---|---|
| `~/workspace/your_files/lullaby-mix-variants/bed_brown.wav` | ホワイトノイズの漏れあり積分 (ランダムウォーク) | 200–800: -7.0、800–3200: -6.1 dB/oct |
| `~/workspace/your_files/lullaby-mix-variants/bed_pink.wav` | Voss-McCartney ピンクノイズ | 200–800: -3.5、800–3200: -3.5 dB/oct |

両案の差は 800 Hz 以上で大きく、1600–3200 Hz 帯のレベル差は約 16 dB。
ピンク案の実測が理想の -3 ちょうどではなく -3.5〜-4.1 なのは Voss 法の近似と
心音の裾の混入によるもので、ブラウン案との区別には影響しない。
ブラウン案の 200–400 Hz が -7.8 とやや急なのも同じ理由 (心音の裾) で、
800 Hz 以上では -6.0〜-6.1 と狙い通り。

## 残る判断 (泰崇)

1. **bed_brown と bed_pink を同じ音量で聴き比べ、どちらが「こもった子宮の土台」
   に近いか選ぶ。** 音楽は入っていないので、土台だけの印象で選べる。
   (実験版の音源は求められない限りこちらから再生・提示しない方針のため、
   ファイルの場所だけを伝え、聴くのは泰崇が聴きたいとき。)
2. 選んだ方を `render_mix.py` のフロー層に採用する。その際、音楽層の
   羊水フィルタ (現行は 1500 Hz・12 dB/oct の仮値) は**別問題**として触らない。
   1500 Hz は周波数中央値と一致するが、12 dB/oct の傾き自体は未検証の仮値。
3. 音圧の中央値 60 dB は再生時の音量キャリブレーションの話で、WAV の
   正規化では決まらない。別ステップとして扱う。

## 決定 (2026-11-17)

- 泰崇の試聴判断で **ブラウンを採用**。`render_mix.py` のフロー層を漏れあり
  積分 (ブラウン) に置き換えた。レベルは旧フロー (400 Hz×3段) の RMS に
  一致させてあり、変わったのはスペクトル形だけ。新ベッドの実測は
  200–800 Hz −7.0、800–3200 Hz −6.1 dB/oct で、試聴で選ばれた
  bed_brown.wav と同一。全体 RMS も旧ベッドと同等 (0.0443 vs 0.0441)。
  これで上の「残る判断」1・2 は完了。
- あわせて泰崇の指示: **心音の周波数 (現行 55 Hz) は、実測の心音スペクトルに
  基づかなくてよい**。胎内のイメージと聴感で決める設計判断として扱う
  (`render_mix.py` の Parameter bases に明記)。値そのものは当面 55 Hz のまま。
- 同日夜の試聴フィードバックで確定: 心音の音色は実測スタイルのままでよい
  (イメージ基準の許可は使わない)。問題は音色ではなくレベルで、**心音・血流
  とも主張が強すぎる**ため両ゲインを −4 dB 下げた (心音 0.32→0.20、
  血流 0.16→0.10、2026-11-15 の弱体化と同じ段幅)。ミックス内の
  ベッド/音楽 RMS 比は約 −0.3 dB → −4.4 dB に。両層を同じ比率で下げた
  のでスペクトル形は不変。試聴ファイルは bed_only_brown_soft.wav /
  mix_3layer_brown_soft.wav。
