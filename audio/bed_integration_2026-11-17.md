# ベッド第1弾×第2弾の照合・統合 (2026-11-17)

## 材料

- **第1弾 (抽出駆動)**: 498件抽出の設計統計。周波数中央値 1500 Hz・音圧
  中央値 60 dB は採用済み。傾斜は Attenuation 5値では決められず、
  試聴でブラウン (−6 dB/oct) を採用 (2026-11-17)。
- **第2弾 (一次文献駆動)**: 胎内伝達の一次文献13件の補強
  (`literature/bed_literature_reinforcement.xml`、数値は原文引用と
  照合 38/38)。錨は Gerhardt 1990 (ヒツジ実測)。
- **統合データセット**: `literature/bed_transfer_evidence.csv`。
  混ぜてはいけない量 — 伝達傾斜 / 刺激・フィルタ傾斜 / 背景スペクトル /
  4 kHz 減衰 / 低域レベル — をグループに分けてラベル付けした。
  除外の記録: 抽出の 96 dB/oct (PMID 1880297、マスキング用ハイパス
  傾斜)、Gélat 2025 (計算モデル、実測ではない)、Peters 1993 の
  800–2000 Hz 増強 (定性的証拠として本文にのみ残す)。

## 照合結果

1. **傾斜は独立に一致した。** 一次文献で伝達傾斜そのものが明記された
   唯一の値 Gerhardt 6 dB/oct は、第1弾で耳が選んだブラウンの
   −6 dB/oct と同じ。抽出の刺激傾斜 (6, 6, 12, 12) も 6 を下端に含む。
2. **相違は 250 Hz 以下だけ。** ブラウンは低域でも上がり続けるが、
   Gerhardt は 250 Hz 未満で +2〜+5 dB の増強〜平坦、Richards (ヒト) も
   125 Hz で +3.7 dB。ベッド実測でも 125 Hz 帯で約8 dB の差
   (第1弾 +7.7 vs 第2弾 −0.5、250 Hz 帯基準)。統合形は
   「250 Hz 以下は平坦、それ以上 −6 dB/oct」= 第2弾の形になる。
3. **ヒトとヒツジの差は未解消のまま残す。** Richards は端点傾斜
   ≈2.7 dB/oct・4 kHz 最大 10 dB と Gerhardt (6 dB/oct・平均 20 dB)
   より緩やか。統合曲線は Gerhardt を錨、Richards を緩やかな下限
   (感度側) として併記する。(第3弾でヒト側を補強した結果、この
   枠組みは「ヒト同士のばらつきが錨を両側から挟む」に更新された。
   末尾の第3弾セクション参照)
4. **単一傾斜は理想化である。** Gélat 2019 (ヒツジ高分解能実測) は
   1 kHz 以下で最小 2–3 dB、11 kHz で最小 3 dB と、伝達が単調でない
   ことを示す。ベッドの実用帯域では錨で代表させ、この留保を残す。

## 統合伝達曲線 (設計目標)

- 250 Hz 以下: **+3.5 dB** (Gerhardt の明記範囲 +2〜+5 の中点。
  Richards の +3.7 とも整合し、低域レベルの統計中央値 3.7 の付近)
- 250 Hz 超: **−6 dB/oct**。4 kHz で −20.5 dB となり、原典の
  「4 kHz で平均 20 dB」と 0.5 dB 以内で一致 (曲線が自らの出典の
  端点を再現する自己整合チェック)
- 感度下限: Richards 端点直線 (2.74 dB/oct、+3.7 @125 Hz → −10 @4 kHz)

## 4曲への照らし合わせ

方法: Klank レンダー (素の4曲) をプロジェクト標準の方法
(8192点 Hann 窓・50% オーバーラップ) で測定し、統合曲線を解析的に
通した。生データは `analysis/song_transfer_comparison.csv`、
図は `analysis/bed_integration.html`。

- 4曲とも素の時点で重心が低い。スペクトル重心は ブラームス 755 /
  モルダウ 874 / 歌に生き 544 / ゆりかご 659 Hz。1500 Hz 以上の
  エネルギー割合は全曲 約1.1–1.2% しかない。
- 錨通過後の全体減衰: **歌に生き −1.7 dB (最も胎内に近い)** <
  ゆりかご −3.1 < ブラームス −4.2 < **モルダウ −5.0 dB (最も明るく、
  最も削れる)**。重心は 426–574 Hz に下がる。Richards 下限では
  減衰 −1.5〜−3.2 dB。
- 帯域形は4曲とも「500–1000 Hz に集中、2000 Hz 帯が谷、4000 Hz 帯に
  Klank の 6.27 倍音が載る」形 (倍音比 1, 6.267, 17.5, 34.4 に対応)。
- 含意: 現行ミックスの音楽層フィルタ (1500 Hz・12 dB/oct の仮値) は
  統合曲線 (250 Hz 折れ・−6 dB/oct) と形が違う。音楽層の胎内処理を
  統合曲線に寄せるかは次の判断で、今回のベッド統合では触っていない。

## 実装 (2026-11-17、泰崇の指示で実施)

残る判断の 1・2 を両方とも実施し、`render_mix.py` に反映した。

- **血流層**: 整形を統合曲線に変更 (250 Hz の1極ローパス = 250 Hz
  以下は平坦、それ以上 −6 dB/oct)。レベルは FLOW_RMS_PER_GAIN ×
  GAIN_FLOW のまま不変。
- **音楽層**: 羊水フィルタを仮値 (1500 Hz・12 dB/oct) から統合曲線
  (同じ 250 Hz・−6 dB/oct) に変更。挿入損失で音楽の RMS が
  0.0461 → 0.0153 に下がるため、GAIN_MUSIC を 1.10 → 3.31 (実測
  ×3.01) に上げて補償し、試聴で確定したベッド/音楽比 (−10.4 dB) を
  維持した (再レンダー実測 −10.5 dB)。
- **検証**: 新ベッドの回帰傾斜は 200–800 Hz −4.5、800–3200 Hz
  −5.9 dB/oct。第2弾 (FFT 整形の厳密形) は −5.8 / −6.1 で、上帯域は
  0.2 以内で一致。200–800 が浅いのは 250 Hz の折れ目をまたぐ帯域で、
  1極フィルタの滑らかな膝 (250 Hz で −3 dB) によるものと特定済み。
  厳密形が要る場合は第2弾スクリプトの FFT 整形に差し替え可能
  (render_mix.py の標準ライブラリ縛りとのトレードオフ)。
- 試聴ファイル: bed_only_integrated.wav / mix_3layer_integrated.wav
  (ベッドのゲインは半減後の心音 0.10 / 血流 0.05 のまま)。

## 第3弾: ヒト実測のみの狭い補強 (2026-11-17)

経緯と探索記録の正本は `literature/bed_literature_round3_human.md`。
点データは `literature/bed_transfer_curves.csv`、曲線表は
`analysis/bed_curve_comparison.csv` (Python) と
`analysis/bed_curve_comparison_r.csv` (R) — 両実装の数値は
**完全一致 (最大差 0.0)**。

### 取れたもの・取れなかったもの

- **Richards 1992 本文: 取れなかった。** LWW の有料壁の向こうで、
  オープンな著者稿も無し。中間の 1/3 オクターブ帯域値は一次源から
  抽出できず、端点直線 (2.74 dB/oct) は計算値のまま据え置き。
  二次情報として「250 Hz 未満の帯域は最大 5 dB 増強」(Spence &
  Freeman 1996 が Richards に帰属) があり Gerhardt の +2〜+5 と
  整合するが、データには入れていない。
- **Querleu の帯域値: 一次源では確認できなかった** (仏誌一次論文と
  1988 年総説の本文に到達できず)。ただし独立した二次源3件が一致:
  Muenssinger 2013 (Front Hum Neurosci、PMC 全文で逐語確認)
  「2 dB @250 Hz、14 @500、20 @1000、26 @2000」(Querleu et al.
  1988 に帰属、破水後・分娩開始時に胎児頭部近傍のハイドロホン)、
  Spence & Freeman 1996 (250 Hz で 2 dB・1000 Hz で 20 dB を
  1981 年論文に帰属)、Busnel らの総説 (ヒトは 250 Hz 以下 0〜2 dB、
  1000 Hz で約 20 dB、動物の減衰はヒトより小さいと明記)。
  → `kind=secondary_corroborated` として分離保管し、設計値には
  使わず曲線比較にのみ使う。
  （訂正 2026-11-18: 本節の旧表記「Moon & Fifer 1996」は誤帰属。
  正しくは Spence & Freeman 1996 (Infant Behav Dev 19:199-212、
  DOI 10.1016/S0163-6383(96)90019-3)。公開スキャンで p.200 の
  引用文を逐語確認済み。値・結論は不変。レジストリは
  spence_freeman_1996、旧 ID は再利用しない。）
- Nyman 1991 は接触式人工喉頭の子宮内レベル (最大 129 dB) と判明し
  伝達曲線には使えない (Gerhardt 1988 と同種)。Walker 1971 は
  一次資料に到達できず据え置き。

### 曲線比較 (レベル変化 dB、外 − 内)

| 周波数 | Richards (端点直線) | 錨 (Gerhardt) | Querleu (二次裏付け) |
|---|---|---|---|
| 250 Hz | +0.96 | +3.5 | −2 |
| 500 Hz | −1.78 | −2.5 | −14 |
| 1000 Hz | −4.52 | −8.5 | −20 |
| 2000 Hz | −7.26 | −14.5 | −26 |
| 4000 Hz | −10.0 | −20.5 | (範囲外) |

- **錨は全周波数で2つのヒト曲線の間に来る。** 従来の留保は
  「ヒトは緩やか (Richards) かもしれない」だったが、実際はヒトの
  実測同士の開き (1000 Hz で 15.5 dB) が、錨と近い方のヒト曲線との
  距離 (4.0 dB) より大きい。「種差」ではなく「ヒト側の研究間
  ばらつき」が不確かさの本体、というのが更新後の正確な記述。
- **傾斜 6 dB/oct は3度目の収束。** Querleu の区間傾斜は
  250→500 Hz が −12、500→1000 と 1000→2000 がいずれも −6 dB/oct。
  Gerhardt の明記値・耳で選んだブラウンに続き、500 Hz 超の傾斜は
  ヒト側の点データでも 6 になった。Querleu との相違は傾斜ではなく
  膝の段差 (250→500 の落ち込み) と棚の無さ (250 Hz で増強でなく
  −2 dB) にある。
- **設計への影響: なし (錨は動かさない)。** 新しい一次明記値が
  得られていない以上、二次データを根拠に錨を動かすのはこの
  プロジェクトの規則に反する。ヒト側のブラケットは Richards
  (緩) と Querleu (急) の2曲線に更新され、感度側の下限として
  Richards を併記する従来の扱いは維持する。将来ヒト錨の変種を
  作るなら、この2曲線が両端になる。

## 仮説（2026-11-17、未検証）: 粗さはノイズの色ではなく段差のartifactだったのではないか

- 仮説: 第1弾でブラウンとピンクを聴き比べたときの「粗さ」は、
  ノイズの色（スペクトル傾斜 −6 / −3 dB/oct）そのものではなく、
  血流層の surge 包絡にあった拍ごとのゲイン段差（最大 0.442）に
  由来していた可能性がある。段差は両候補に共通の包絡処理に
  あったため、色の比較が粗さの比較に汚染されていたかもしれない。
- 根拠となる経緯: 段差の発見と 25 ms 平滑化による除去は、
  聴き比べでブラウンを採用した後の SoX ベッド試作で起きた
  （粗さの指標は 1.61 → 1.55 dB に改善）。つまり色の選択は
  段差が残った状態で行われており、平滑化後に色の比較は
  やり直されていない。
- 含意: 段差を除去した現在の生成系でピンク（−3 dB/oct）を
  作れば、ベッド候補として再評価に値する可能性がある。
  現行の採用（統合伝達曲線のベッド）はこの仮説では変更しない。
- 検証方法（将来）: 現在の生成系（種固定・平滑化済み）で
  ピンク整形のベッドを作り、粗さの指標（中間部・50 ms 窓の
  レベル SD、現行ベッドで 1.55 dB）と帯域エネルギーを測って
  現行ベッドと比較し、その後に聴き比べる。
- 留保: 粗さがスペクトル由来の成分を持つ可能性は残る
  （ピンクは高域エネルギーが多く、粗さの知覚が段差だけに
  還元できるとは限らない）。仮説の成否は測定と試聴で決める。
