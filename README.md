# A Music Box to Help Babies Sleep

胎内音響プロファイリングに基づく、赤ちゃん寝かしつけ用オルゴール PWA。

作り手の主観（恣意性）を排し、音響学・小児科学・発達心理学の文献データから
導き出したパラメータに基づいて、新生児・乳児の入眠と自律神経の安定を促す
Web アプリを、無料・完全オープンソースで開発するプロジェクト。

目的は収益ではなく、赤ちゃんの睡眠研究が前に進むことと、睡眠と発達の
関連を追うこと。広く知ってもらうための発信（売り込み）はその手段として
行う。方法論とデータを公開し、誰が使ってもよい形にすることで、他の
誰かが続きを進められる状態を作る。

- 広告・課金要素なし

## 構成

3つの音響レイヤーを独立にミックスできる設計。

| レイヤー | 内容 |
|---|---|
| オルゴール | パブリックドメイン楽曲を無限ループ化した主旋律（倍音を抑えた音色） |
| 心音 | 母体安静時心拍（BPM 60〜80）を基準に、導入時は速めから減速するエントレインメント |
| さざ波（胎内音） | 羊水の中の音響環境そのもの。母体の血流音を主体とする暗騒音をノイズ生成で自作し、心音の BPM に同期してゆらがせる |

数値パラメータ（BPM・周波数帯域・音圧上限など）は文献レビューの
実測集計から決める。ただしテンポは、文献統計としては存在せず、
生理学側の仮定として扱う（`METHODOLOGY.md` の「統計処理と
パラメータ決定ルール」の節の初回集計。仮定の出典・更新条件は
【要決定：CONF-010】。裁定記録は `CONTRADICTIONS.md` の CA-004 の項参照）。
決定ルールと母集団は [METHODOLOGY.md](METHODOLOGY.md)、
音響・UX の設計仕様は [DESIGN.md](DESIGN.md) を参照。

## 文書の正本と優先順位

文書・記録・データの間で記述が食い違う場合に、どれを正とするかを
この節に定める。上位のものが下位のものに勝つ。

扱わない。

| 順位 | 文書群 | 扱い |
|---|---|---|
| 1 | 中核の仕様文書（`README.md`、`DESIGN.md`、`METHODOLOGY.md`） | 正本。不一致があった場合は、この階層の記述が勝つ |

## 文書要件

文書の一覧・更新契機・版管理・言語、仕様と実装の不整合時の正本の扱いを
定める。文書の正本の階層と矛盾の扱いは、この文書の「文書の正本と
優先順位」の節が定めており、この節はそれを書き換えない。記録文書の
目録・状態表示の規則は、同節の「記録文書の状態表示と目録」の項が定める。
版の付け方の方式・互換性の方針・変更履歴の置き場所の一般規則は、
CONF-065 の決定に従う。この節の規則のうち（推奨）と記したものは、
原作者の確認を経るまで確定事項として扱わない。要決定と記した要素は、
原作者の決定を待つ。

- 文書の一覧：文書の一覧と、各文書の作成対象・更新契機は、次の表の
  とおりとする。作成するかどうかの決定は、【要決定：CONF-070】とする。

| 文書 | 状態 | 更新契機 |
|---|---|---|
| 中核の仕様文書（`README.md`、`DESIGN.md`、`METHODOLOGY.md`） | 存在する | 仕様の変更のたびに更新する |
| `SECURITY.md`、`GLOSSARY.md`、`PARAMETERS.md`、`CONTRADICTIONS.md` | 存在する | 所管する決定の変更のたびに更新する |
| `docs/TESTING_AND_PERFORMANCE.md` | 存在する | テスト・性能の決定の変更のたびに更新する |

  とはみなさないことは、「文書の正本と優先順位」の節の定めに従う。
