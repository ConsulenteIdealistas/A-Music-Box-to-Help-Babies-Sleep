# A Music Box to Help Babies Sleep

胎内音響プロファイリングに基づく、赤ちゃん寝かしつけ用オルゴール PWA。

作り手の主観（恣意性）を排し、音響学・小児科学・発達心理学の文献データから
導き出したパラメータに基づいて、新生児・乳児の入眠と自律神経の安定を促す
Web アプリを、無料・完全オープンソースで開発するプロジェクト。

目的は収益ではなく、赤ちゃんの睡眠研究が前に進むことと、睡眠と発達の
関連を追うこと。広く知ってもらうための発信（売り込み）はその手段として
行う。方法論とデータを公開し、誰が使ってもよい形にすることで、他の
誰かが続きを進められる状態を作る。

## 構成

3つの音響レイヤーを独立にミックスできる設計。

| レイヤー | 内容 |
|---|---|
| オルゴール | パブリックドメイン楽曲を無限ループ化した主旋律（倍音を抑えた音色） |
| 心音 | 母体安静時心拍（BPM 60〜80）を基準に、導入時は速めから減速するエントレインメント |
| さざ波（胎内音） | 羊水の中の音響環境そのもの。母体の血流音を主体とする暗騒音をノイズ生成で自作し、心音の BPM に同期してゆらがせる |

数値パラメータ（BPM・周波数帯域・音圧上限など）はすべて文献レビューの
実測集計から決める。決定ルールと母集団は [METHODOLOGY.md](METHODOLOGY.md)、
音響・UX の設計仕様は [DESIGN.md](DESIGN.md) を参照。
