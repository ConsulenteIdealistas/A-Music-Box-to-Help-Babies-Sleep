4曲の完成ミックスとエビデンス (2026-11-17)

4曲すべてを、確定した設計で3層ミックス (オルゴール+心音+血流ベッド) として描き出した。各道具の担当はプロジェクトの役割分担どおり: SuperCollider (Klank でオルゴールを生成、MusicXML が正本) → Python (render_mix.py でミックス。音楽と血流に統合伝達曲線、 心音 70 BPM) → SoX (完成ファイルのレベル統計を独立に測定) → R (robustbase で Python/SoX の一致検証と4曲の要約統計)。 帯域図は各ファイル自身の 125–8000 Hz 合計に対する帯域シェア (dB)。

設計の根拠: 伝達曲線は Gerhardt 1990 (ヒツジ実測) の錨 — 250 Hz 以下 +3.5 dB、それ以上 −6 dB/oct (曲線図は bed_curves.html)。 引用は reference_id: gerhardt_1990、レジストリは analysis/evidence_references.csv。 心音 70 BPM (母体安静時心拍 60–80 の中央、可変パラメータ)、55 Hz は 実測スタイルの音色。ゲインは試聴で2段階弱めた確定値 (心音 0.10 / 血流 0.05 / 音楽 3.31 = 統合曲線の挿入損失を実測 ×3.01 で補償)。 ベッド/音楽比は較正用の短いフレーズでは −10.4 dB だったが、実際の 4曲で測ると中央値 −15.8 dB になった (曲ごとにフレーズの鳴っている 割合が違うため。ゲイン自体は変えていない)。
