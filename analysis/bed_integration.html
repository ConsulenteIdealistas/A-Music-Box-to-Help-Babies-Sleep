ベッド統合 — 伝達曲線と4曲の照合 (2026-11-17)

第1弾 (抽出→ブラウン) と第2弾 (一次文献の伝達曲線) の統合結果。数値の正本は literature/bed_transfer_evidence.csv、統計は analysis/bed_integration.py / .R (相互検証済み)。

1. 統合伝達曲線 (子宮内 − 外部, dB)

錨 (Gerhardt 1990, ヒツジ): 250 Hz 以下 +3.5 dB (明記範囲 +2..+5 の中点)、それ以上 −6 dB/oct。 4 kHz で −20.5 dB となり、原典の「4 kHz で平均 20 dB」と 0.5 dB 以内で一致する。 Richards 1992 (ヒト) は端点 (+3.7 dB @125 Hz → −10 dB @4 kHz) を結んだ緩やかな下限。 ブラウン直線は 250 Hz より下で際限なく上がる点だけが錨と違う。

2. 4曲とベッドの帯域プロファイル (250 Hz 帯 = 0 dB の相対値)

実線 = 素の帯域プロファイル、破線 = 錨曲線を通した後。曲は元々 500–1000 Hz に エネルギーが集中し、1500 Hz 以上の帯域は全体の約 1.1% しかない。
