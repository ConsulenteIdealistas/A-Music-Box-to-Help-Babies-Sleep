# 外部指標・文献の引用規律

外部から持ち込む数値・指標・文献は、誰が読んでも出所と裏付けの
強さが追える形にする。この文書が正本であり、監査計画・監査
台帳・設計文書・生成する図表はすべてこの規律に従う。
（文献抽出そのものの規則は literature/ 側の METHODOLOGY.md が
正本。本規律は、抽出済み・収集済みの値を「引用し、使用する」
側を担う。）

## 1. 中央レジストリへの登録

- 外部の数値・指標・文献をプロジェクト内で引用する場合は、
  先に analysis/evidence_references.csv に登録する。未登録の
  外部数値を、設計文書・台帳・図表に書かない
- レジストリが引用の単一の正本である。文書ごとに別々の書式で
  出典を書き散らさない
- reference_id は一度決めたら変更しない。再利用もしない

## 2. フィールドの定義

- reference_id: 引用を一意に指す安定した ID
- title: 文献・規格の正式な題名
- doi / url: 一次源へ到達するための情報
- source_conditions: その数値が得られた条件。対象集団、測定法、
  距離、音量設定、曝露時間など、数値の意味を決める条件を書く
- applicability: 本プロジェクトの条件との差と、その引用を
  使える範囲・使えない範囲
- linked_parameters: 関係する監査台帳の parameter_id
- notes: 照合の経緯、訂正履歴
- verification_status / verified_on: 照合状態（§3）と、
  照合を行った日付

## 3. 照合状態の定義と、使える範囲

- primary_verified: 一次源（論文の抄録または本文、規格の原文）を
  直接読み、数値と条件を照合した。設計値の錨に使える
- secondary_corroborated: 一次源に到達できないが、独立した
  二次源が2件以上、数値と条件で一致した。設計値の錨には
  使えない。曲線の比較や文脈付けにのみ使える
- existence_confirmed: 文献・規格の存在と書誌情報のみ確認した。
  本文の数値を主張の根拠に使えない
- unverified: 登録しただけで未照合。いかなる主張の根拠にも
  使えない

照合したら verified_on に日付を入れて状態を上げる。訂正で
状態を下げる場合は、notes に理由と経緯を残す。

## 4. 照合の手順

1. 一次源に当たる。書誌情報と見出し級の数値は抄録で足りるが、
   設計を左右する数値は本文で照合する
2. 数値・単位・条件を原文と突き合わせる
3. 報道・解説サイト・まとめは二次源として扱い、一次源の
   代わりにしない
4. 一次源に到達できない場合は、推測で埋めず、状態を
   secondary_corroborated 以下に置く

## 5. 借用値の扱い

- 他の文脈の基準値（病院環境の推奨値、成人の職業曝露基準など）
  を参照する場合は、監査台帳の borrowed_from に借用元を
  記録し、applicability に本来の文脈と本プロジェクトとの
  差を書く
- 借用値を、本プロジェクト自身の基準であるかのように
  書かない
- 合否基準に借用値を使う場合は、測定前に借用であることを
  明記したうえで固定する（監査計画の合否基準の事前登録と連動）

## 6. 使用箇所での出典明記

外部数値を使う文書・図表では、使用箇所の近くに reference_id を
併記し、レジストリへ1 hop で辿れるようにする。

## 7. 訂正と履歴

- 誤りが見つかったら、該当エントリの notes に訂正内容と日付を
  追記し、verification_status を見直す
- エントリの削除は、その引用がプロジェクト内のどこからも
  参照されなくなった場合のみ行う
